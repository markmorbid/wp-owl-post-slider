# wp-owl-post-slider
A minimal plugin to create post/entry based sliders and carousels with owl library. Fully responsive and works with any WordPress theme. Based on soe old but nice deprecated plugins, in an open source fully free version. 

# Owl Slider unificado

Proyecto local recuperado desde la conversación de Codex.

- `preview.html`: comparación local autónoma de las versiones PSAC y PSACP.
- `owl-test-corregido.html`: exportación HTML corregida.
- `owl-cards.css`: estilos compartidos para ambas estructuras.
- `assets/`: dependencias locales, fuentes e imagen de prueba.
- `reference/`: los dos archivos HTML originales aportados en el chat.
- `releases/owl-unificado.zip`: paquete descargable con la entrega original.
- `LEEME.md`: instrucciones detalladas para WordPress y registro de validación.

Para revisar la comparación local:

```bash
python -m http.server 8000
```

Luego abrir `http://localhost:8000/preview.html`.
